📁 WEBSITE FILES
--------------------------------------------------------

index.html
→ মূল ওয়েবসাইটের হোম পেজ।

admin.html
→ ওয়েবসাইটের Admin Panel।

data.js
→ ওয়েবসাইটের ডেটা।

config.js
→ ওয়েবসাইটের সেটিংস।

script.js
→ মূল ওয়েবসাইটের JavaScript।

admin.js
→ Admin Panel-এর JavaScript।

style.css
→ ওয়েবসাইটের ডিজাইন।

logo.png
→ মাদ্রাসার লোগো।

========================================================
                 IMPORTANT
========================================================

১. index.html অবশ্যই Root Folder-এ থাকতে হবে।

২. CSS/JS ফাইলের নাম পরিবর্তন করা যাবে না,
   যদি HTML-এর ভিতরে নাম পরিবর্তন না করা হয়।

৩. logo.png একই ফোল্ডারে রাখতে হবে।

৪. ছবি যোগ করলে সঠিক Image URL ব্যবহার করতে হবে।

৫. অনলাইনে Admin Panel নিরাপদ করার জন্য
   Backend Authentication ব্যবহার করা উচিত।
